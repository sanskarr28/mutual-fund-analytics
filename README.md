# 📈 Mutual Fund Analytics Engine

An end-to-end data engineering, quantitative analysis, and BI visualization pipeline for Indian Mutual Funds.

## 🛠️ Technical Stack
* **Python:** Pandas, NumPy, SQLite3, SciPy
* **Visualization:** Power BI, Matplotlib, Seaborn
* **Analytics:** Risk-Adjusted Returns (Sharpe, Sortino, Alpha), Tail Risk (VaR, CVaR), Sector Concentration (HHI)

## 🚀 How to Run the Project
1. Clone the repository.
2. Navigate to the directory: `cd mutual_fund_analytics`
3. Install requirements: `pip install pandas numpy matplotlib seaborn scipy`
4. Execute the master pipeline: `python run_pipeline.py`
5. Open `dashboard/bluestock_mf_dashboard.pbix` in Power BI Desktop to view the interactive visualizations.
